# Instagram Downloader

Instagram 게시물 URL 또는 아이디를 입력하면 이미지/영상과 본문(caption.txt)을 저장합니다.

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python app.py
```

저장 위치:

```
downloads/
 └ username/
    └ 날짜_shortcode/
       ├ 이미지/영상
       └ caption.txt
```

주의: 본인이 접근 권한이 있는 콘텐츠에 사용하세요.
